# Workroom

Workroom 系列的索引仓库。各项目在自己的 GitHub 仓库维护介绍、源码和使用入口。

| 项目 | 用途 |
| --- | --- |
| [仙女座 Andromeda](https://github.com/geniusdapeng-collab/workroom-andromeda) | WorkLoom 平台的运营与运维工作台。 |
| [鹰眼 Eagle](https://github.com/geniusdapeng-collab/workroom-eagle) | 面向咨询团队的客户档案、诊断和持续服务工作台。 |
| [狐狸先生 Fox](https://github.com/geniusdapeng-collab/workroom-fox) | 以酒店场景试验数字员工的 3D 汇报与交互。 |
| [老虎 Tiger](https://github.com/geniusdapeng-collab/workroom-tiger) | 全球资产管理研究与模拟盘系统。 |

共享协作底座见 [WorkLoom IM](https://github.com/geniusdapeng-collab/workloom-im)。系列中的预留仓在各自 README 标明状态。
